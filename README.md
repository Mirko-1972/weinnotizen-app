# Meine Weinnotizen

Private mobile Web-App für Weinverkostungsnotizen mit Supabase.

## Felder
Name, Weingut, Jahrgang, Land, Region, Rebsorte, Verkostungsdatum, Bewertung, Körper, Intensität, Mundgefühl, Farbe, Aromen Nase, Aromen Mund, Spiel, Alkohol, Gerbstoffe/Bitterstoffe, Abgang und ein Bild.

## Konfiguration
Die wichtigsten Feldnamen und Auswahlwerte stehen in `src/config.js`.
